How I Turned My Linux PC into a T3 Code Server I Can Use from Anywhere

A short, step-by-step guide.

My Linux PC runs T3 Code as a background service, all the time. Tailscale connects it privately to my MacBook and my Android phone. Nothing is open to the public internet.

You need:

  • A Linux PC (I used Ubuntu)
  • Node.js
  • Tailscale on the PC and on every device you want to connect from

Step 1: Install T3 Code as a service

npm i -g t3
t3 service install
loginctl enable-linger $USER

This installs T3 Code, runs it as a background service, and starts it at boot, even if nobody logs in. Check it:

t3 service status

You should see Status: installed.

Step 2: Turn on Tailscale Serve

First, let your own user manage Tailscale Serve:

sudo tailscale set --operator=$USER

Then add a small settings file (a systemd drop-in) to the T3 service:

mkdir -p ~/.config/systemd/user/t3code.service.d

cat > ~/.config/systemd/user/t3code.service.d/tailscale.conf <<EOF
[Service]
Environment=T3CODE_TAILSCALE_SERVE=1
Environment=PATH=$HOME/.local/bin:$(dirname $(which node)):/usr/local/bin:/usr/bin:/bin:/snap/bin
EOF

systemctl --user daemon-reload
systemctl --user restart t3code

This file survives T3 updates. The PATH line matters because the service can't otherwise see where Node CLIs (like Codex) are installed. If you switch Node versions with nvm, run it again.

Check it:

tailscale serve status

You should see a private address like https://my-pc.tailXXXXX.ts.net. The first HTTPS certificate can take a few seconds, so if it doesn't load right away, wait and try again.

Step 3: Pair your laptop and phone

On the PC:

t3 pair --tailscale

In the T3 Code app, go to Add Environment → Remote link, then paste the link or scan the QR code.

The code expires after 5 minutes. Need more time? Use t3 pair --tailscale --ttl 1h.

Can't connect?

If you see something like this, your device can't reach the PC:

Failed to fetch remote environment endpoint ... (HttpClientError: Transport error ...)

Check these, in order:

  1. Tailscale is Connected on the device.
  2. Mac: Tailscale menu → Settings → turn on Use Tailscale DNS.
  3. Android: Settings → Private DNS → Off. "Automatic" didn't work for me.
  4. The pairing code hasn't expired.

Step 4: Install your agent CLIs

T3 Code runs agents through their command-line tools, so install them on the PC. For Codex:

npm i -g @openai/codex
codex login status

The PATH line from Step 2 lets the service find them.

Step 5: Keep it reachable

Stop the PC from sleeping:

sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target

Tailscale logins expire after about 6 months. In the Tailscale admin console, click ⋯ next to your PC and choose Disable key expiry.

Updating T3 Code

Golden rule: keep the PC, the t3 command and all your apps on the same channel, and run updates on the PC itself:

t3 update --channel nightly --yes

(Use stable, preview or nightly, whichever your other devices use.)

That's it: T3 Code on my PC, from anywhere. 🚀

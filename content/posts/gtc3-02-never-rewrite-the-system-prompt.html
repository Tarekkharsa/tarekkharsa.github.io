Model providers cache the start of your request. If the system prompt is byte-for-byte the same as last turn, you pay less and wait less. Most agents break that cache all the time without noticing: the current date, the git branch, the open files or the active rules get re-rendered into the system prompt on every turn.

This repo's rewrite treats the system prompt as something you never rewrite mid-conversation.

Freeze the baseline

At the start of a Context Epoch, the runtime renders the full system context once. That baseline then stays "the immutable provider-cache baseline" until something that really requires a new one: a completed compaction, moving the session, or an incompatible change.

Append what changed

The context is built from typed Context Sources, each with a stable key, a JSON codec and pure renderers. The runtime keeps a snapshot of the last value it showed the model for each source. When one changes, it doesn't edit the baseline. It appends a Mid-Conversation System Message with the newly effective state. Roughly, with made-up sources:

turn 1   [baseline: rules, environment, branch=main]  user  assistant
turn 2                                                  user  assistant
turn 3   [update: branch is now fix-login]              user  assistant
         ^ appended, so everything before it stays cached

The rules that make it work

  • Lazy, not pushed. Changes are "sampled and admitted lazily at a Safe Provider-Turn Boundary, never pushed asynchronously when their source changes."
  • One message per boundary. Changes from several sources at the same boundary combine into a single update.
  • Deterministic order. Producers run concurrently but combine in stable key order, so the same state always renders the same text. Duplicate keys fail.
  • Stale beats missing. If a source temporarily can't be read, the previous value stays in effect and nothing is emitted. That's different from a source that's really gone, which can emit removal text.
  • Exact text is stored. The update persists the exact text sent to the model, so replay is faithful.

Steal this

Render the system prompt once per epoch and never edit it. Track what the model last saw for each piece of context, and append changes at turn boundaries. Your cache hit rate, and your bill, will thank you.

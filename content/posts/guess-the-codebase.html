Every round, I read one open-source codebase cover to cover: the server, the clients, the lint rules, the CI, the PR templates, even the bot configs. Then I turn what I learned into a game. Every repo I pick is one I'd hold up as an example of good engineering.

How to play

  1. Each round has eight lessons from one repo. Each lesson teaches one engineering idea, using real code and docs from it.
  2. Each post ends with three hints about where it came from. Hints pile up from lesson to lesson within a round.
  3. Post your guess on X with #GuessTheCodebase before you open the reveal.
  4. Each round's finale reveals the repo and adds power-user tips for actually using it.

Most tools that have both a server and an embeddable SDK end up with two APIs. The HTTP one is used by remote clients. The "local" one calls internal functions directly, because it's faster and easier. Slowly they drift: a validation that only runs over HTTP, a field that only the local path returns, an auth check one of them skips.

This repo's next SDK refuses to have a second API.

A fetch that never leaves the process

The embedded client builds the real server routes, turns them into a web handler, and hands the normal generated client a fetch function that calls that handler directly:

const web = HttpRouter.toWebHandler(createEmbeddedRoutes(), { ... })

const fetch = (input, init) => web.handler(new Request(input, init))

const client = yield* Client.make({ baseUrl: "http://[name].local" })
  .pipe(Effect.provideService(FetchHttpClient.Fetch, fetch))

Every embedded call is a real Request going through the same router and handlers as a remote one. Only the transport is in-memory. The project's glossary even warns against calling it a "local implementation".

Generated, never hand-written

  • The public HTTP API is the source of truth. Promise and Effect clients are generated from it, and the agent guide says never to edit the generated folders by hand.
  • A runtime-neutral "SDK Contract IR" sits in between, so independent SDK generators can each choose their own value model and runtime from the same definition.
  • Even pagination is one shape everywhere: a Page of items with opaque previous and next cursor links.

Direction is a rule

Keep runtime dependencies directed from Schema to Core and Protocol, then from Core and Protocol to Server. Client runtime code may depend on Schema and Protocol but never Core or Server.

The client can't take a shortcut into the server's internals: the rule says it never imports them.

Steal this

If you ship an embedded mode, run it through your public API with an in-memory transport instead of calling internals. Generate the clients, forbid client imports of server code, and the two modes can't drift.

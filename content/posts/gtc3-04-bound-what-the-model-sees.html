An agent runs npm test, a build, or a grep over a big repo, and one tool result is suddenly megabytes of text. If it all goes into the conversation, it fills the context window, costs a fortune on every later turn, and buries the one line that mattered.

This repo's rewrite puts every tool result through one choke point with one limit.

Output under both limits passes through unchanged. Over either one, the model gets the beginning and the end with a marker in between, and the full text is saved to a file whose path is in the marker.

The rules

  1. One aggregate limit per tool resultThe configured maximum lines or UTF-8 bytes, whichever is reached first: 2,000 lines or 50 KB by default. It's provider-independent; token pressure is handled later, by context assembly and compaction.
  2. Tools shape, the registry enforcesA tool may first turn its output into something more useful for the model. The tool registry applies the final limit to every tool, so no tool can forget.
  3. Keep both endsGeneric truncation keeps the first half and the last half of the allowed lines. For build and test output, the end is usually where the error is.
  4. Lose nothingThe complete text is written to a managed tool-output file, and its path appears in the visible marker and as a typed field, so the model (or a later tool call) can open it.

The careful parts

Byte-safe cuts

Head and tail are cut by UTF-8 byte size one character at a time, so a multi-byte character is never split in half.

The marker fits too

Room for the marker is reserved inside the limit, so the bounded result itself never exceeds it.

Files are never overwritten

Each file gets a new ascending ID and is created with an exclusive flag. Old ones are cleaned up after a 7-day retention.

Structure untouched

Only the text the model sees is bounded. The tool's validated structured result is never modified.

Steal this

Put every tool result through one choke point with one limit. Keep the beginning and the end, save the rest to a file whose path the model can see, cut on character boundaries, and never let a tool opt out.

Run five AI agents in five git worktrees on one machine and everything that's normally shared starts colliding: ports, databases, processes, even the URLs you send to your phone. This repo's dev tooling assumes that's the normal case.

▶

Try it: fixed ports vs hashed ports

add worktrees, then restart everything

With a fixed dev port, the second worktree can't start its server. Deriving the port from a hash of the worktree path gives every worktree its own port, and the same one after every restart.

Ports from a hash of the worktree path

The dev runner derives ports from a hash of the worktree path, so the result depends on where a worktree lives, not on who started first. Two details show how carefully it was built:

  • It skips every port on the Fetch spec's blocked list, the ones curl accepts but browsers refuse to connect to.
  • It probes only loopback when checking whether a port is free. Probing wildcard addresses made it move away from a free port whenever tailscale serve held the same number on another interface.

Everything else is per worktree too

State

Each worktree gets its own gitignored data directory, and it deliberately takes priority over any ambient HOME-style variable, so you can't land on shared state by accident.

Setup

A script runs when a worktree is created: it links the shared .env and warms the dependency cache.

Origin

Dev is single-origin: Vite proxies /api and /ws. Baking localhost into the bundle "silently breaks every remote browser."

Sharing

vp run dev --share publishes the dev server on the tailnet and prints a pairing URL for your phone. The mapping goes away when the process exits.

Vendored reference repos

A .repos/ folder holds read-only source of key libraries, skipped by CI's sparse checkout. Agents read real library code instead of guessing from training data. The rules: never edit them, never import from them, re-sync when you bump the dependency.

CI that doesn't wait in line

  • Lint, typecheck, build and tests run as parallel jobs behind one aggregate "Check" gate.
  • System packages install in the background while JS dependencies install.
  • A new push to a PR cancels its superseded runs.

And the one rule that makes all of this safe to automate, never killing processes by pattern, is in lesson 8.

Steal this

Design dev tooling as if a dozen strangers share your laptop, because with agents that's roughly true. Derive ports and state from the worktree path, keep one origin, and make a new worktree ready in one step.
